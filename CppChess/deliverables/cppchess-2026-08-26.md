## 3. 架构与 VB 版对齐

| 层次 | C++ 文件 | 对应 VB | 职责 |
|------|----------|---------|------|
| 数据层 | `chess_core.h / GameState` | `ChessCore.vb` | 8×8 字符数组棋盘、行棋方、易位权、过路兵格、局面键历史 |
| 规则层 | `chess_core.cpp / Rules` | `ChessCore.vb` | 伪合法走法生成 → 轻量克隆试走 → `IsAttacked()` 过滤送王着法 |
| 终局层 | `chess_core.cpp / Rules` | `ChessCore.vb` | 将军 / 将死 / 逼和 / 三次重复 / 50 步 / 子力不足（含 KNN、异色格象、KBB、KBN 真实和棋判定） |
| 评估层 | `chess_ai.cpp / AIEngine::Evaluate` | `ChessAI.vb` | 子力价值（P100/N320/B330/R500/Q900）+ 位置价值表 PST（黑方取白方行镜像） |
| 搜索层 | `chess_ai.cpp / AIEngine` | `ChessAI.vb` | negamax + alpha-beta 剪枝 + MVV-LVA 走法排序 + 静态搜索 quiescence（限深 4） |
| 表现层 | `main.cpp` | `ChessUI.vb`（控制台版） | 控制台交互 / 自对弈 / 计时 / 自测入口 |

**坐标约定（与 VB 一致）**：`row 0` = 第 8 横线（黑底线），`row 7` = 第 1 横线（白底线）；大写=白、小写=黑、`'.'`=空。

**调研结论**：经典引擎棋盘表示有 mailbox 8×8 / 0x88 / bitboard 三类。本版与 VB 保持 **mailbox 8×8 字符数组**，零依赖、易对齐、规则正确性优先；极致性能可后续单独迁移 bitboard（参考 Chess Programming Wiki / yvl-chess / Stockfish）。

## 4. 编译（g++ / MSVC 双编译器自动探测）

`build.bat` 全程无需手动配环境：

1. **优先 g++（MinGW-w64）**：依次探测 `PATH` → `C:\tools\mingw64` → `C:\ProgramData\chocolatey\bin` → `C:\msys64\mingw64\bin` → `E:\mingw64\bin`
2. **g++ 未找到时自动切 MSVC**：`vswhere.exe` 动态定位任意盘符 VS 安装 → 显式候选 **`F:\VS2022` 排第一**（用户指定盘符，避开 C 盘）→ 兜底标准 C: 路径（Community/Professional/Enterprise/BuildTools）→ `call vcvars64.bat` 初始化后用 `cl` 编译

手动等价命令：
```bat
:: g++
g++ -std=c++17 -O2 -o bin\cppchess.exe main.cpp chess_core.cpp chess_ai.cpp tests.cpp
:: MSVC（装到 F:\VS2022 时）
call "F:\VS2022\VC\Auxiliary\Build\vcvars64.bat"
cl /std:c++17 /O2 /EHsc /utf-8 /nologo /Fobin\ /Fe:bin\cppchess.exe main.cpp chess_core.cpp chess_ai.cpp tests.cpp
bin\cppchess.exe test
```

### 5.2 静态可编译性复核（已做）

### 5.3 build.bat 本次修复（关键）
用户本机执行 `.\\build.bat` 报 `此时不应有 and。`（cmd 语法解析错误）。

**根因**：原脚本把含 `(x86)` 的路径放进了 `for (...)` 列表/命令串，而 **cmd 的 `for` 元字符括号不受引号保护**，会把 `C:\Program Files (x86)` 中 `(x86)` 的 `)` 误判为 `for (...)` 块结束，导致后续 token 解析错乱。

**修复（三处规避，全部零括号风险）**：
1. vswhere 检测：改为「直接执行 + 判 `if not errorlevel 1`」，不再把 `(x86)` 路径放进 `if exist "(x86)" (` 块；结果先 `> %TEMP%` 落盘
2. 读 vswhere 结果：用 `for /f "usebackq delims=" ... in ("%TEMP%\cppchess_vswhere.txt")` **读文件**（读文件不触发括号误判），替代在 `for` 命令串里塞路径
3. 候选路径：全部改为逐条 `if exist "PATH" set VAR=PATH` 简单判断（引号内 `(x86)` 对 `if exist` 安全），删除原 `for %%D in (含括号列表)`

**该坑已记入跨项目记忆**（`~/.workbuddy/MEMORY.md` 的「Windows .bat 编码铁律」），避免复发。
