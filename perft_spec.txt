================================================================================
perft 黄金值测试规范（跨语言一致契约）
================================================================================
目的：用 chessprogramming wiki 的标准 perft 位置，对 8 个语言版本做
      **语言无关**的正确性交叉验证（能抓出"同源移植 bug"——大家都错但一致）。

perft 定义（纯走法生成计数，不调用 AI/评估）：
    perft(state, depth):
        if depth == 0: return 1
        moves = GenerateLegalMoves(state)        # 各语言已有的合法走法生成入口
        if depth == 1: return len(moves)
        count = 0
        for m in moves:
            child = state.Clone()                # 深度拷贝 GameState（含 board/易位权/过路兵/半步计数）
            ApplyMove(child, m)
            count += perft(child, depth - 1)
        return count

要求：
  - 使用各语言引擎**已有的** GenerateLegalMoves / Clone / ApplyMove（与 97 项测试同一套）。
  - 若某语言缺 Clone()，需补一个深拷贝（board 8x8 + 全部状态字段）。
  - 位置用**显式 8x8 字符串数组**构建（rank8 在最前，即 board[0]=rank8…board[7]=rank1），
    不依赖 FEN 解析器。棋子字母同 C++：白大写/黑小写/'.' 空。

建议纳入测试套件的断言（控制单测运行时间在数秒内，兼顾覆盖）：
  Check("Perft Start d3 = 8902",      perft(start,3)==8902)
  Check("Perft Start d4 = 197281",    perft(start,4)==197281)
  Check("Perft Kiwipete d3 = 97862",  perft(kiwipete,3)==97862)
  Check("Perft Pos3 d4 = 43238",      perft(pos3,4)==43238)
  Check("Perft Pos5 d3 = 62379",      perft(pos5,3)==62379)
（性能强的语言可额外加 Kiwipete d4=4085603 / Pos5 d4=2103487，但须确保不显著拖慢整体测试）

注意：
  - 这些值是公开、语言无关的真相，任何一个版本算错都说明其走法生成有 bug。
  - 加到各语言现有测试 harness（与 97 项 Check 并列），run_tests() 失败时返回失败计数。
  - 不要运行测试（由主控在工具链就绪后统一运行）。
